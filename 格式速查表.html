文字樣式

<b>粗體文字
加粗文字
<i>斜體文字
傾斜文字
<u>底線文字
加底線
<s>刪除線文字
劃除文字

字體大小

<size<1>>最小 (0.7em)
<size<3>>標準 (1em)
<size<5>>大 (1.5em)
<size<7>>超大 (2.5em)

顏色設定

<color<red>>紅色
<color<orange>>橘色
<color<cyan>>青色
<color<#ff6b6b>>自訂色
使用 Hex 色碼

對齊方式

<pivot<l>>靠左
<pivot<c>>置中
<pivot<r>>靠右

縮排

<tab<1>>縮排1單位
<tab<2>>縮排2單位
<tab<3>>縮排3單位

特殊樣式

<ct>子標題
黃色底線標題
<imp>重要訊息
黃框強調區塊
<link<網址>>文字
超連結

程式碼區塊

```py
def hello():
print("Hello")
```
支援語言: py, js, cpp, c, cs, java
```js
[width<full>]
console.log("全寬");
```

表格

[table]
<imp>標題1
[c]<imp>標題2
資料1
[c]資料2
[/table]
[c] = 新儲存格，<imp> = 標題樣式
[table]
[width<full>]
...
[/table]

樹狀圖

[tree]
[id<1>] 根節點
[id<2> p<1>] 子節點1
[id<3> p<1>] 子節點2
[/tree]
id = 節點ID, p = 父節點ID

組合範例

<pivot<c>><size<6>><color<orange>>大標題
置中+大字+橘色
<size<4>><color<cyan>><b>重點
大字+青色+粗體

💡 提示：點擊「複製」按鈕快速複製格式！
