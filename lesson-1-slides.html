def find_by_cost(card_list, cost):
    result = []
    for card in card_list:
        if card["cost"] == cost:
            result.append(card["name"])
    return result

一模一樣的形狀：list 裡面裝 dict
四個小差別
1.<cont> 文字一定要用<b>雙引號</b> `"`，不能用單引號
2.<cont> `True` / `False` 要寫成 <b>`true` / `false`</b>，小寫
3.<cont> 每一筆後面要逗號，<b>最後一筆不能有</b>
4.<cont> <b>不能寫註解</b>
寫錯的話，遊戲啟動時會告訴你錯在哪一行

加一張卡

動手做

1.<cont> 複製 `mods/example_mod` 資料夾
2.<cont> 改名成你的名字，例如 `mods/alex_mod`
3.<cont> 打開 `mod.json`，改 `id` 和 `name`
4.<cont> 打開 `cards.json`，加一張卡
5.<cont> 存檔，回遊戲按 <color<orange>><b>F5</b>
id 只能用小寫英文、數字、底線，不能有中文或空格
JSON
{"id": "fireball", "name": "火球", "type": "attack", "cost": 2, "damage": 15}
{"id": "fireball", "name": "火球", "type": "attack", "cost": 2, "damage": 15}
| 欄位 | 意思 | 限制 |
|---|---|---|
| id | 這張卡的代號 | 小寫英文數字底線 |
| name | 顯示的名字 | 最多 5 個中文字 |
| type | attack / skill / power | 決定框線顏色 |
| cost | 費用 | 0 到 5 |
| damage | 傷害 | 可換成 block、heal |
遊戲啟動時會顯示<color<yellow>>載入報告
報告會告訴你
哪個<b>檔案</b>、第<b>幾筆</b>資料
哪個<b>欄位</b>錯了
