# 語法速查

打字時快速查閱用。各種格式的實際效果請看[格式參考](格式參考.md)。

## 基本規則

| 規則 | 說明 |
|---|---|
| `<b i>文字` | 行首最多一個角括號，裡面用空白分隔多個格式，不寫結尾 |
| `<size=5 color=red>文字` | 有參數的格式寫 `name=value`，只切第一個 `=` |
| `<color="rgb(255, 0, 0)">文字` | 值含空白或 `>` 時用雙引號包起來 |
| `<color=red color=blue>文字` | 同一名稱寫兩次，後面的蓋掉前面的（藍色） |
| 名稱要完全相同 | 大小寫也要一致；有一個名稱不認識，整行照原樣顯示並警告 |
| 值不合法 | 例如 `size=9`、`pivot=x`、`b=1`，整行照原樣顯示並警告 |
| `<b>` 後面的空白 | 會被去掉（cont 行除外） |

## 文字格式

套用在文字上，也可以用在清單項目和 cont 行。

| 寫法 | 說明 |
|---|---|
| `b` 或 `bold` | 粗體 |
| `i` 或 `italic` | 斜體 |
| `u` 或 `underline` | 底線 |
| `s` 或 `strike` | 刪除線；`u s` 同時有底線和刪除線 |
| `size=1` 到 `size=7` | 字級：0.7em、0.85em、1em、1.2em、1.5em、2em、2.5em |
| `color=名稱或色碼` | 顏色，例如 `color=orange`、`color=#4ecdc4`（名稱見下表） |
| `link=網址` | 超連結，例如 `link=https://example.com/?a=1` |

## 整行格式

作用在整行，不能用在清單項目和 cont 行（會忽略並警告）。

| 寫法 | 說明 |
|---|---|
| `ct` | 子標題：黃色、粗體、底線 |
| `imp` | 重要區塊：黃色框、置中 |
| `tab=N` | 縮排 N 層，每層 2em |
| `pivot=l`、`pivot=c`、`pivot=r` | 靠左、置中、靠右 |
| `img=路徑或網址,寬,高` | 圖片；寬高是像素或 `auto`，路徑以 .md 所在資料夾為基準 |

## 顏色名稱

已針對深色背景調亮。自訂色碼（例如 `#ff0000`）不會被調整。

| 名稱 | 色碼 | 名稱 | 色碼 |
|---|---|---|---|
| `red` | `#ff9999` | `orange` | `#ffa500` |
| `green` | `#00d200` | `purple` | `#d79eff` |
| `blue` | `#adadff` | `pink` | `#ffc0cb` |
| `yellow` | `#ff0` | `gray` | `#b6b6b6` |
| `cyan` | `#0ff` | `white` | `#fff` |
| `black` | `#000`（在深色卡片上看不清楚，不建議使用） | | |

## 接續上一行：cont

| 寫法 | 說明 |
|---|---|
| `<cont color=red>後半段` | 接在上一行後面，不換行；連續多行 cont 都接在同一行 |
| `<cont b> word` | `>` 後面的空白會保留，英文單字之間的空格寫在這裡 |
| 文字格式 | 每段只套自己寫的，不繼承上一段 |
| 整行格式 | 由第一行決定，作用於整行（imp 的接續段在框內）；寫在 cont 行會忽略並警告 |
| 不能接的情況 | 段落第一行、表格或程式碼區塊後緊接的行，會當一般行並警告；表格儲存格和樹節點不支援 |

## 清單

| 寫法 | 說明 |
|---|---|
| `- 項目` | 行首減號加空白，項目符號依層級為 • ◦ ▪ |
| `  - 第二層` | 每 2 個空白或 1 個 Tab 多一層（奇數空白無條件捨去） |
| `- <b color=red>重點` | 項目後面可以接文字格式；符號大小跟著 size，顏色固定白色 |
| `- 前半` 下一行 `<cont>後半` | cont 接在同一個項目裡 |
| 不支援的地方 | 表格儲存格和樹節點裡的 `- ` 是普通文字 |

## 跳脫

| 寫法 | 說明 |
|---|---|
| `\<b>` | 行首的 `\<` 顯示字面上的 `<`，整行不解析（儲存格和樹節點也適用） |
| `\-` | 行首的 `\-` 顯示字面上的 `-`，不當清單 |
| 行中間的 `<` | 直接寫即可，只有行首會被解析 |

## 標題與分頁

| 寫法 | 說明 |
|---|---|
| `# 標題` | 投影片標題 |
| `## 副標題` | 投影片副標題；只有副標題時放在標題的位置 |
| `---` | 單獨一行，分隔投影片 |
| 程式碼區塊裡的 `#` 和 `---` | 不影響標題和分頁 |

## 區塊

| 寫法 | 說明 |
|---|---|
| ` ```py ` 到 ` ``` ` | 程式碼區塊；語言見下方 |
| `[width=full]`、`[width=400px]` | 寫在區塊裡（習慣放第一行），設定寬度；程式碼、表格、樹狀圖都適用 |
| `[table]` 到 `[/table]` | 表格；每一行是新的一列，`[c]` 開頭是同一列的下一格；第一列自動加粗 |
| `[c]<imp>標題` | 儲存格也能用行首格式；`imp` 讓該格像標題列 |
| `[tree]` 到 `[/tree]` | 樹狀圖，支援任意深度 |
| `[id=2 p=1] 文字` | 樹節點：`id` 是編號，`p` 是上層節點的編號；沒有 `p` 的是根節點 |

程式碼語言：`c`、`cpp`（`c++`）、`cs`（`c#`）、`py`（`python`）、`js`（`javascript`）、`java`、`bash`（`sh`、`shell`）、`html`（`htm`）、`css`、`json`；其他語言顯示為不上色的程式碼。

## 警告

格式寫錯時，該行照原樣顯示成文字，並在終端機印出 `檔名:行號: 訊息`，簡報仍然會生成。常見原因：

- 名稱打錯，或值不合法
- 行首的角括號沒有寫結尾的 `>`
- 一行寫了兩個角括號（例如 `<b><i>文字`，第二個會顯示成文字）
- 空的 `<>`
- 樹節點方括號裡寫了 `id`、`p` 以外的設定
- 找不到圖片、圖片超過 1 MB

## 已廢除

`<a><b>`（一行多個角括號）、`name<arg>`（角括號參數）、樹節點的 `o<1/2>` 與 `imp`。舊簡報請用 `tools/migrate_syntax.py` 轉換，見[使用指南](使用指南.md#舊簡報轉換)。
