# 使用指南

依照實際使用的順序說明：安裝、生成、上台、列印、放圖片、轉換舊簡報。語法請查[語法速查](語法速查.md)，各種格式的效果請看[格式參考](格式參考.md)。

## 安裝

需要 Python 3.9 以上。在工具資料夾（`start.bat` 所在的資料夾）開啟命令視窗，執行一次：

```bash
pip install -e .
```

之後在任何資料夾都可以使用 `briefgen` 指令。若系統找不到 `briefgen`（Python 的 Scripts 資料夾不在 PATH），把 `briefgen` 換成 `python -m briefgen` 即可。

## 簡報資料夾

啟動器把簡報集中放在「文件」資料夾底下的 `brief`：

- Windows：`文件\brief`（「文件」被 OneDrive 或自己搬到其他位置時，會跟著實際的位置）
- macOS：`~/Documents/brief`
- Linux：系統設定的「文件」資料夾（例如 `~/文件`）底下的 `brief`，沒有設定時是 `~/Documents/brief`

第一次啟動時會自動建立，並顯示位置；可以在啟動器的「設定」修改。每份簡報一個資料夾：

```text
brief\講義\講義.md       簡報內容
brief\講義\講義.html     生成的簡報
brief\講義\images\      這份簡報用的圖片
```

不在 `brief` 裡的 .md 也可以使用，規則相同。

## 用啟動器操作

Windows 雙擊 `start.bat`（其他系統執行 `python launcher.py`），出現中文選單：

| 選項 | 做什麼 |
|---|---|
| [1] 開啟 / 生成簡報 | 從最近使用的 5 份或開檔視窗選擇 .md，生成 HTML |
| [2] 即時預覽 | 同樣的選法，存檔後瀏覽器自動更新；按 Ctrl+C 回到選單 |
| [3] 新增簡報 | 輸入名稱，在 `brief` 建立資料夾、空白範本和 `images` 資料夾（同名不會覆蓋） |
| [4] 轉換舊簡報 | 把舊語法轉成新語法，轉換前自動備份成 `名稱.v2.bak.md` |
| [5] 開啟簡報資料夾 | 用檔案總管開啟 `brief` |
| [6] 說明 | 開啟語法速查（線上版或用記事本開本機版），或生成並開啟格式參考 |
| [7] 生成範例 | 把範例簡報複製到 `brief\範例` 並生成，可以直接修改來練習 |
| [8] 設定 | 變更簡報資料夾、清除最近使用清單 |

- 生成的 HTML 一律存在 .md 旁邊、檔名相同（`講義.md` 生成 `講義.html`），生成完成後可以直接開啟簡報或所在資料夾
- 子選單都可以按 0 或直接按 Enter 回到上一層
- 沒有開檔視窗時（例如沒有安裝 tkinter），可以輸入路徑，或把 .md 檔拖進視窗
- 最近使用的清單和設定存在家目錄的 `.briefgen\launcher.json`

### 拖曳開啟

把 .md 檔拖到 `start.bat` 上，會直接開始即時預覽，不必經過選單；按 Ctrl+C 結束後回到選單。

## 命令列：生成簡報

```bash
briefgen build -i 講義.md -o 講義.html
```

- `-i`：輸入的 Markdown 檔（只接受 .md）
- `-o`：輸出的 HTML 檔，省略時為目前資料夾的 `presentation.html`
- `-t "標題"`：瀏覽器分頁上的標題；省略時依序取第一張投影片的 `#` 標題、`##` 副標題、檔名

輸出是單一 HTML 檔，本機圖片已經嵌在裡面，可以直接搬移或傳給別人。

## 命令列：即時預覽

```bash
briefgen watch 講義.md
```

- 自動開啟瀏覽器；每次存檔都會重新生成，頁面自動重新載入並停在原本那一張
- 生成的 HTML 寫在 Markdown 旁邊（`講義.html`），可用 `-o` 指定位置
- `--no-open` 不自動開啟瀏覽器，`--port` 指定埠號（預設自動選擇）
- 格式有警告時頁面照常更新，右上角列出警告與行號
- 生成失敗時（例如檔案編碼錯誤）保留上一個成功的版本，並在角落顯示錯誤
- 按 Ctrl+C 結束

## 上台操作

在瀏覽器開啟生成的 HTML。翻頁器送出的是 PageUp / PageDown，可以直接使用。

| 按鍵 | 動作 |
|---|---|
| `→` | 下一張 |
| `←` | 上一張 |
| `↓`、空白鍵、`PageDown` | 投影片還沒捲到底時先往下捲一個畫面，已在底部才翻到下一張 |
| `↑`、`PageUp` | 還沒捲到頂時先往上捲，已在頂部才翻回上一張 |
| `Home` / `End` | 第一張 / 最後一張 |
| `F` | 切換全螢幕 |
| `B` | 切換黑屏；黑屏時按翻頁鍵只會恢復畫面，不換頁 |

網址後面的 `#12` 記住目前頁數，重新整理或直接開啟 `講義.html#12` 會停在第 12 張。

## 列印與 PDF

在瀏覽器開啟生成的 HTML，按 Ctrl+P（Mac 為 Cmd+P），目的地選「另存為 PDF」。

- 每張投影片一頁，16:9 橫式，不含導覽列與按鈕
- 保留深色背景與程式碼配色
- 太寬的樹狀圖、太長的投影片會等比例縮小放進一頁

## 圖片

```text
<img=images/架構圖.png,600,auto>
```

- 寫法是 `img=路徑或網址,寬,高`，寬高是像素，也可以寫 `auto`（依原圖比例）
- 本機圖片的路徑以 .md 檔所在的資料夾為基準：把圖片放進簡報資料夾裡的 `images`，寫成 `<img=images/圖.png,400,auto>`
- 生成時圖片會嵌進 HTML，所以只要傳一個 HTML 檔就好
- 路徑有空白時，整個值用雙引號包起來，例如 `img="我的 圖片/a.png,400,auto"`
- `http://`、`https://` 開頭的網址維持原樣，播放時需要連網
- 找不到檔案時會警告並附上行號，圖片位置顯示「找不到圖片」；超過 1 MB 的圖片會提醒先壓縮

## 舊簡報轉換

3.0 起的語法和舊版不相容。舊版寫法像 `<size<5>><b>文字`、`[width<400px>]`、`[id<2> p<1>]`，請用轉換工具改寫：

```bash
python tools/migrate_syntax.py 舊簡報.md -o 新簡報.md
python tools/migrate_syntax.py 舊簡報.md --in-place
```

| 舊語法 | 新語法 |
|---|---|
| `<size<5>><color<red>><b>文字` | `<size=5 color=red b>文字` |
| `<link<https://a.com>>文字` | `<link=https://a.com>文字` |
| `[width<400px>]` | `[width=400px]` |
| `[id<2> p<1> o<1/2>]` | `[id=2 p=1]` |

轉換報告印在終端機，列出需要留意的內容：

- 舊版沒有作用、新語法也不接受的格式（例如 `size<9>`、未知名稱）會被移除
- 樹節點的 `o<...>` 與 `imp` 已廢除，會被移除
- 段落行首的 `[注意]` 這類方括號，舊版會被隱藏，新語法會顯示成文字
- 寫在行中間的標籤（例如 `文字<b>粗體`）不會套用格式，請手動拆成 cont 行

轉換後建議生成一次，確認沒有格式警告。已經是新語法的檔案再轉換一次不會被改動。

## 常見問題

### 路徑有中文或空白怎麼辦？

可以正常使用。在命令列輸入時，整個路徑用雙引號包起來：

```text
briefgen build -i "C:\Users\我\Documents\我的 簡報\講義.md" -o "D:\網頁\講義.html"
```

輸出可以放在任何資料夾，不必和 .md 在一起。

### 終端機出現「檔名:行號: 訊息」是什麼？

那是格式警告，例如名稱打錯或值不合法。有警告的那一行會照原樣顯示成文字，簡報仍然會生成。依照行號回到 .md 修正即可。

### 一次生成很多份簡報？

在工具資料夾建立 `batch_build.bat`：

```text
@echo off
cd /d "%~dp0"
briefgen build -i "slides/lecture1.md" -o "output/lecture1.html"
briefgen build -i "slides/lecture2.md" -o "output/lecture2.html"
echo 全部完成
pause
```

### 可以把簡報傳給別人嗎？

可以。生成的 HTML 是單一檔案，本機圖片已經嵌在裡面；對方用瀏覽器開啟即可，不需要安裝任何東西。只有使用網址的圖片需要連網。
