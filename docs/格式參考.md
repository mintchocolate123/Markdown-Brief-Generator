# 語法規則
## 只在行首標格式，不寫結尾

```text
<b i>粗體+斜體
<pivot=c size=6 color=orange>置中的大標題
<link=https://example.com/?a=1>連結
```

- 每行行首最多一個角括號，裡面用空白分隔多個格式
- 無參數的格式直接寫名稱：b、i、u、s、ct、imp、cont
- 有參數的格式寫 name=value，只切第一個等號
- 名稱必須完全相同（大小寫也要一致）
- 同一名稱寫兩次時，後面的蓋掉前面的

# 接續上一行
## cont：在同一行中途換格式

```text
<b>粗體開頭，
<cont color=red>接著紅色，
<cont i> then italic
```

<b>粗體開頭，
<cont color=red>接著紅色，
<cont i> then italic

- cont 行接在上一行後面，不換行；連續多行 cont 都接在同一行
- cont 的 > 後面的空白會保留，英文單字之間的空格寫在這裡
- 每段只套自己寫的文字格式（b、i、u、s、size、color、link），不繼承上一段

---

# 接續的整行格式
## 區塊格式由第一行決定

```text
<imp>重要：
<cont color=red>作業週五截止
```

<imp>重要：
<cont color=red>作業週五截止

- pivot、tab、ct、imp 寫在第一行，作用於整行（含接續段）
- 這些格式寫在 cont 行會被忽略並警告
- 段落第一行、表格或程式碼區塊後緊接的行不能用 cont，會當一般行並警告
- 表格儲存格與樹節點不支援 cont

# 跳脫
## 顯示字面上的角括號

```text
\<b>這行不是格式
```

\<b>這行不是格式

- 行首寫 \< 表示字面上的 <，整行不解析
- 只有行首需要跳脫，行中的 < 直接寫即可

---

# 格式錯誤的警告
## 寫錯時整行照原樣顯示

```text
<bold size=9>size 只有 1 到 7
<b 忘了寫結尾
<b><i>一行只能有一個角括號
```

- 名稱不認識或值不合法時，整行當普通文字顯示
- 生成時在 stderr 印出警告與行號，例如：
```text
slides.md:12: 格式 size 的值不合法：9，整行視為文字
```
- 舊語法的檔案請用 tools/migrate_syntax.py 轉換

```text

```

---

## 圖片的路徑與注意事項

- 本機圖片的路徑以 .md 檔所在的資料夾為基準，生成時嵌進 HTML，單一檔案就能搬移或傳給別人
- 路徑有空白時整個值用雙引號包起來：img="我的 圖片/a.png,400,auto"
- http / https 網址維持原樣，播放時需要連網
- 找不到檔案時會警告並附上行號，圖片位置顯示替代文字
- 超過 1 MB 的圖片會提醒先壓縮

# 綜合範例 3
## 快速排序的程式碼

<pivot=c size=5 color=purple>快速排序演算法

```py
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)
```

---

# 上台操作
## 鍵盤與翻頁器

- →：下一張；←：上一張
- ↓、空白、PageDown：先往下捲一個畫面，已經在底部才翻到下一張
- ↑、PageUp：先往上捲，已經在頂部才翻回上一張
- Home / End：第一張 / 最後一張
- F：全螢幕；B：黑屏（再按 B 或任何翻頁鍵恢復，不會換頁）
- 翻頁器送出的是 PageUp / PageDown，可以直接使用

<imp>網址的 #12 記住目前頁數，重新整理後會停在同一張

# 即時預覽
## 存檔就更新

```bash
briefgen watch 講義.md
```

- 自動開啟瀏覽器；每次存檔都會重新生成並自動重新載入，停在原本那一張
- 有格式警告時頁面照常更新，右上角列出警告與行號
- 生成失敗時保留上一個成功的版本，並在角落顯示錯誤
- HTML 寫在 Markdown 旁邊（可用 -o 指定），不含即時預覽用的程式碼
- 啟動器選 [3] 即時預覽也可以；按 Ctrl+C 結束

# 列印與 PDF
## 每張投影片一頁

- 在瀏覽器按 Ctrl+P，目的地選「另存為 PDF」
- 每張投影片一頁，16:9 橫式，不含導覽列與按鈕
