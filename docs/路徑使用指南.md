# 如何處理不同資料夾的簡報

## 方法 1：使用完整路徑（最簡單）

雙擊 `start.bat`，選擇 [1]，然後輸入完整路徑：

```
請輸入 Markdown 檔案路徑: C:\Users\薄荷巧\Documents\slides\my_presentation.md
輸出檔案 [預設: my_presentation_output.html]: C:\Users\薄荷巧\Documents\slides\output.html
```

**提示**：可以直接從檔案總管複製路徑！
1. 在檔案上按 Shift + 右鍵
2. 選「複製為路徑」
3. 貼到命令列

---

## 方法 2：使用相對路徑

假設你的檔案結構：
```
我的文件/
├── 簡報工具/        ← start.bat 在這裡
│   ├── start.bat
│   ├── launcher.py
│   ├── src/
│   └── ...
└── 我的簡報/
    └── lecture.md   ← 你的簡報在這裡
```

在 `start.bat` 輸入：
```
請輸入 Markdown 檔案路徑: ..\我的簡報\lecture.md
輸出檔案: ..\我的簡報\lecture_output.html
```

**相對路徑符號**：
- `.` = 當前目錄
- `..` = 上一層目錄
- `..\..` = 上兩層目錄

---

## 方法 3：把簡報檔放到工具目錄（最方便）

直接把 `.md` 檔案放到 `start.bat` 同一個資料夾：

```
簡報工具/
├── start.bat
├── launcher.py
├── src/
└── my_slides.md       ← 你的簡報
```

然後只需輸入檔名：
```
請輸入 Markdown 檔案路徑: my_slides.md
```

---

## 方法 4：命令列直接指定

開啟命令提示字元（cmd），切換到工具目錄：

```cmd
cd C:\path\to\簡報工具
set PYTHONPATH=src
python -m briefgen build -i "C:\Users\薄荷巧\Documents\slides\my.md" -o "C:\Users\薄荷巧\Documents\slides\output.html"
```

`set PYTHONPATH=src` 讓 Python 找得到 `src/briefgen`，同一個命令視窗只需要設定一次。

## 常見問題

### Q: 路徑有中文會怎樣？
A: 沒問題！但建議用**引號**包起來：
```
"C:\使用者\薄荷巧\我的簡報\lecture.md"
```

### Q: 路徑有空格會怎樣？
A: 一定要用引號：
```
"C:\My Documents\My Slides\lecture.md"
```

### Q: 可以直接在檔案總管開啟嗎？
A: 可以！在你的 `.md` 檔案所在資料夾：
1. 按住 Shift + 右鍵點空白處
2. 選「在此處開啟 PowerShell 視窗」或「在此處開啟命令視窗」
3. 執行（`set` 在 cmd 使用；PowerShell 請改用 `$env:PYTHONPATH="C:\path\to\簡報工具\src"`）：
   ```
   set PYTHONPATH=C:\path\to\簡報工具\src
   python -m briefgen build -i lecture.md -o output.html
   ```

### Q: 輸出一定要跟輸入同資料夾嗎？
A: 不用！輸出可以放任何地方：
```
輸入：C:\Users\薄荷巧\Documents\lecture.md
輸出：D:\網頁\簡報\output.html  ← 完全不同的地方
```

## 推薦工作流程

**方案 A - 簡單使用者**：
1. 所有 `.md` 檔案都放工具目錄
2. 雙擊 `start.bat`
3. 輸入檔名即可

**方案 B - 進階使用者**：
1. `.md` 檔案放任何地方
2. 雙擊 `start.bat`，輸入完整路徑或相對路徑
3. 輸出預設與輸入同資料夾

**方案 C - 專業使用者**：
1. 用命令列 + 完整路徑
2. 可以寫批次腳本自動化
3. 可以整合到其他工作流程

---

## 批次處理多個簡報

在工具目錄創建 `batch_build.bat`：

```batch
@echo off
cd /d "%~dp0"
set PYTHONPATH=%~dp0src
python -m briefgen build -i "slides/lecture1.md" -o "output/lecture1.html"
python -m briefgen build -i "slides/lecture2.md" -o "output/lecture2.html"
python -m briefgen build -i "slides/lecture3.md" -o "output/lecture3.html"
echo 全部完成！
pause
```

一次生成多個簡報！
